# External Review README — Fixed Case D={3,4,7}, k=1 

## Package status

This package is **externally reviewable**. It includes a **replayable computational certificate** and a **locally replayed PASS** log.

Do not describe this package as externally verified unless an independent reviewer runs and accepts the verifier.

## Fixed theorem supported

For the fixed case only,

```text
D = {3,4,7}, k = 1
```

this package supports:

```text
[582,∞) ⊂ A_1({3,4,7})
```

where `A_1({3,4,7})` is the set of integers representable as subset sums of distinct positive powers generated by 3, 4, and 7.

## Non-claims

This package does not claim:

- a general BEGL result,
- a result for all D,
- a result for any D other than {3,4,7},
- a result for k != 1,
- an endpoint below 582,
- optimality of 582,
- a density or asymptotic theorem.

## Main proof chain

The proof uses:

```text
finite interval certificate
+ Conditional Interval-Overlap Propagation Lemma
+ replayed Weighted Gap Lemma certificate
=> global overlap inequality S(t)-t >= 1163
=> interval-overlap propagation
=> [582,∞) ⊂ A_1({3,4,7}).
```

The finite interval certificate is:

```text
[582,4460] ⊂ SubSum(3,4,7,9,16,27,49,64,81,243,256,343,729,1024,2187).
```

The overlap constant is:

```text
P_s = 5042
L_s = 4460 - 582 = 3878
C = P_s - L_s - 1 = 1163
```
