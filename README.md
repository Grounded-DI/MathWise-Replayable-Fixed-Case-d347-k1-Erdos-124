# MathWise — Fixed-Case Replayable Certificate for Erdős Problem #124

A Grounded DI LLC public package for the fixed case `D = {3,4,7}, k = 1`, with a proof record, modular certificate tables, a stored replay log, and provenance artifacts.

## Overview

This repository was created May 4, 2026 and contains ten tracked files. It supports the scoped statement

```text
[582,∞) ⊂ A_1({3,4,7})
```

where `A_1({3,4,7})` is the set of integers representable as subset sums of distinct positive powers generated by 3, 4, and 7.

The package is deliberately narrow. It makes no general BEGL claim, no claim for another set `D`, no claim for `k ≠ 1`, no endpoint below 582, and no optimality, density, or asymptotic claim.

## Key Result

The proof PDF/TeX and the certificate materials state the fixed-case theorem

```text
[582,∞) ⊂ A_1({3,4,7})
```

The proof route is:

```text
finite interval certificate [582,4460]
        + weighted next-gap identities
        + full paired modular certificates
        → S(t) − t ≥ 1163
        → interval-overlap propagation
        → [582,∞) ⊂ A_1({3,4,7})
```

The finite starting certificate uses the ordered powers

```text
3, 4, 7, 9, 16, 27, 49, 64, 81, 243, 256, 343, 729, 1024, 2187
```

## Technical Significance

The record combines a finite interval certificate, explicit weighted gap identities, full paired modular systems, and a stored PASS log. It does not rely only on a prose assertion: the tables expose the candidate counts, modulus sequence, final rows, and zero-survivor status for each of the three weighted cases. The proof also states exactly where imported checkpoint material is used.

## Proof and Certificate Structure

For future powers `t > 2187`, the package reduces interval-overlap propagation to three weighted inequalities:

- `t = 3^r`: `2Δ₄ + Δ₇ ≥ 7002`
- `t = 4^s`: `3Δ₃ + Δ₇ ≥ 7002`
- `t = 7^q`: `3Δ₃ + 2Δ₄ ≥ 7002`

The certificate attachment checks the full paired systems, not only difference equations. It records the closing moduli `17497` (Case A), `257` (Case B), and `1373` (Case C), with the final Case A row `(1909,214)` and final Case C rows `(386,681)` and `(1844,681)` eliminated.

`SHA256SUMS.txt` preserves hashes for artifacts under historical `/mnt/data/...` paths.
